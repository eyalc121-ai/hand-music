# נגן ידיים

אפליקציית דפדפן שמנגנת תווים לפי תנועות הידיים מול המצלמה.

כל אצבע פתוחה מנגנת תו, וסגירת האצבע עוצרת אותו. יד ימין מנגנת דו–סול, יד שמאל מנגנת סול–רה באוקטבה גבוהה, ופתיחת כף היד קובעת את העוצמה. הזיהוי נעשה עם MediaPipe, והצלילים נוצרים ב-Web Audio.

מחאו כפיים — קרבו את מרכזי שתי כפות הידיים — כדי להשהות: כל התווים נעצרים מיד, ואצבעות פתוחות לא מנגנות עד מחיאת כפיים נוספת. על המסך מופיע «⏸ מושהה — מחא כפיים להמשך» או «▶ מנגן».

אחרי «התחל» המחשב פותח חדר PeerJS ומציג קוד QR לכתובת `speaker.html?room=…`. בטלפון לוחצים «הפעל צליל», והתווים, עוצמת היד, השהיה והמשך מושמעים שם. «השמע גם במחשב» פעיל כברירת מחדל. מספר הרמקולים המחוברים מופיע מתחת לקוד.

החיבור עובר בשרת הציבורי החינמי של PeerJS, בלי חשבון ובלי סיסמה: מי שיש לו את הקישור יכול להאזין, חדר עלול ליפול או להתנגש, וחומת אש עלולה לחסום WebRTC. רענון המחשב פותח חדר חדש וצריך לסרוק שוב.

פתחו את [האתר](https://eyalc121-ai.github.io/hand-music/), לחצו על «התחל», ואשרו גישה למצלמה ולשמע.
